The World Wide Web is a system of interlinked documents and resources, accessed over the Internet through browsers, that allows information to be published, linked and navigated using simple point-and-click hyperlinks. The Web is, in fact, only an application on top of that underlying network -- and it didn't arrive until 1989, two decades after the first message was sent on the Internet. It was invented by Tim Berners-Lee, a scientist at CERN, who was trying to solve a much narrower problem: helping physicists at CERN to share research documents and data with each other more easily. What was an internal tool for one research lab became the open, worldwide network of pages we use today after CERN put the software in the public domain in 1993.

Key Milestones

March 1989 — Tim Berners-Lee submits his first proposal

Submitted while working at CERN, for a "distributed information system." This was the original document that eventually became the World Wide Web; he resubmitted a revised version in May 1990.

Source: timeline.web.cern.ch

November 1990 — Formal "WorldWideWeb" proposal with Robert Cailliau

Berners-Lee and CERN colleague Robert Cailliau submit a formal proposal titled "Worldwide Web: Proposal for a Hypertext Project." Formalized the idea into an actual project with a name and management backing.

Source: web30.web.cern.ch

December 1990 — First browser, website, and server go live at CERN

By Christmas 1990, Berners-Lee had defined HTML, HTTP, and URLs, and built the first browser/editor and server; the Web became a working system for the first time rather than just a proposal.

Source: web30.web.cern.ch

April 30, 1993 — CERN puts the WWW software into the public domain

Removed licensing restrictions so anyone could freely build browsers and servers, a decision widely credited as letting the Web spread globally.

Source: home.cern

January–April 1993 — NCSA releases the Mosaic browser

Pre-releases from January 1993, with the official version 1.0 released on April 21, 1993. The first browser to make the Web visually accessible to non-technical users, combining images and text on the same page.

Source: timeline.web.cern.ch

October 1994 — Tim Berners-Lee founds the W3C at MIT

Established the organization that still sets and maintains Web standards (HTML, CSS, etc.) today.

Source: timeline.web.cern.ch

Three Key Technologies

HTML (Hypertext Markup Language)

The language used to structure and format documents so they can be displayed and linked as web pages.

Source: w3.org

HTTP (Hypertext Transfer Protocol)

The protocol that governs how browsers and servers request and send documents back and forth.

Source: w3.org

URL/URI (Uniform Resource Locator/Identifier)

The addressing system that gives every page and resource on the Web a unique, findable location.

Source: w3.org
