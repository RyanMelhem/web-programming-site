Introduction

The World Wide Web is a system of interlinked documents and resources, accessed over the Internet through browsers, that allows information to be published, linked and navigated using simple point-and-click hyperlinks. The Web is, in fact, only an application on top of that underlying network -- and it didn't arrive until 1989, two decades after the first message was sent on the Internet. It was invented by Tim Berners-Lee, a scientist at CERN, who was trying to solve a much narrower problem: helping physicists at CERN to share research documents and data with each other more easily. What was an internal tool for one research lab became the open, worldwide network of pages we use today after CERN put the software in the public domain in 1993. The timeline below follows the Web from the first CERN proposal through the arrival of JavaScript, CSS, Web 2.0, HTML5 and the move to HTTPS, followed by the three key technologies behind it: HTML, HTTP and URLs.

Timeline of the Web

1989: Berners-Lee's first CERN proposal

This was the original document that eventually became the World Wide Web; he resubmitted a revised version in May 1990.

Source: cern.ch

November 1990: Formal "WorldWideWeb" proposal w/ Cailliau

Berners-Lee and CERN colleague Robert Cailliau submit a formal proposal titled "Worldwide Web: Proposal for a Hypertext Project” Formalized the idea into an actual project with a name and management backing.

Source: cern.ch

December 1990: First browser/editor, website, server live

The world's first web browser/editor, website, and server go live at CERN By Christmas 1990, Berners-Lee had defined HTML, HTTP, and URLs, and built the first browser/editor and server; the Web became a working system for the first time rather than just a proposal.

Source: cern.ch

January-April 1993: NCSA releases the Mosaic browser

The first browser to make the Web visually accessible to non-technical users, combining images and text on the same page.

Source: cern.ch

April 30, 1993: CERN releases WWW software into public domain

CERN puts the World Wide Web software into the public domain — Removed licensing restrictions so anyone could freely build browsers and servers, a decision widely credited as letting the Web spread globally.

Source: cern.ch

Oct 1994: Berners-Lee founds the W3C at MIT

Established the organization that still sets and maintains Web standards (HTML, CSS, etc.) today.

Source: cern.ch

1995: JavaScript is created at Netscape

Brendan Eich wrote the first prototype at Netscape in 1995. It shipped as LiveScript in a Navigator beta in September 1995 and was renamed JavaScript in December 1995. Web pages could now react to the user instead of being static.

Source: speakingjs.com

December 1996: CSS1 becomes a W3C Recommendation

CSS1 was published on December 17, 1996. It let designers separate the look of a page from its HTML content.

Source: w3.org

June 1997: ECMAScript standardises JavaScript

The first edition of ECMA-262 was published in June 1997, giving JavaScript a vendor-neutral standard so it could work across browsers.

Source: ecma-international.org

2005: Web 2.0

Tim O'Reilly's essay "What Is Web 2.0" (September 30, 2005) described the shift of the Web from static pages to a platform for services, user-generated content and social participation.

Source: oreilly.com

October 2014: HTML5 becomes a W3C Recommendation

HTML5 was finalised on October 28, 2014. It added native audio and video, semantic elements and new APIs, reducing the need for plug-ins.

Source: w3.org

2015-2018: HTTPS everywhere

Let's Encrypt issued its first free certificate on September 14, 2015. In February 2018 Google announced that from Chrome 68 (July 2018) all HTTP sites would be marked "Not secure", making encrypted connections the default expectation.

Source: security.googleblog.com

Key Technologies of the Web

HTML (Hypertext Markup Language)

The language is used to structure and format documents so they can be displayed and linked as web pages.

Source: w3.org

HTTP (Hypertext Transfer Protocol)

The protocol that governs how browsers and servers request and send documents back and forth.

Source: w3.org

URL/URI (Uniform Resource Locators/Identifiers)

The addressing system that gives every page and resource on the Web a unique, findable location.

Source: w3.org
