Week 3 — Templates and Responsive Design

Week 3 did not add a new page. It changed how the whole site is built. I moved the parts every page shares into one template, base.html, and I wrote a responsive design system in style.css using CSS variables, Flexbox, Grid and media queries. This page shows each of those parts.

1. Template inheritance with base.html

Before Week 3, every page repeated the same header, navigation and footer. Now base.html holds them once and leaves empty blocks for each page to fill in.

{% raw %}<!-- base.html -->
<title>{% block title %}My Web Programming Portfolio{% endblock %}</title>
<header> ... navigation ... </header>
<main>
    {% block content %}{% endblock %}
</main>
<footer> ... </footer>{% endraw %}

Each page only writes what is different about it:

{% raw %}<!-- internet-history.html -->
{% extends "base.html" %}
{% block content %}
    <h2>History of the Internet</h2>
    ...
{% endblock %}{% endraw %}

Flask fills the blocks on the server before the page is sent, so the browser receives one complete HTML page. Changing the navigation in base.html updates every page on the site at once. This page uses the same template too.

2. CSS variables

The colours, fonts, spacing and corner radius are defined once in :root and reused everywhere with var(...). Changing one value changes the whole site.

--text

--primary

--primary-hover

:root {
    --primary: #1b6b6b;
    --radius: 10px;
}
nav a:hover {
    background-color: var(--primary);
}

3. Flexbox

The navigation bar at the top is a Flexbox row. flex-wrap: wrap lets the buttons move to a new line when the screen is too narrow, and gap keeps the same space between them. The boxes below use the same rules. Make the window narrower to see them wrap.

4. CSS Grid

The Weekly Work cards on the home page are a Grid. repeat(auto-fit, minmax(240px, 1fr)) means: fit as many columns as there is room for, each at least 240px wide, and share the leftover space equally. The browser chooses the number of columns by itself, without a media query.

5. Media queries (mobile first)

The base styles are written for phones first. Media queries then add changes as the screen gets wider: from 600px (tablet) the headings grow and the cards go into several columns, and from 1024px (desktop) the headings and navigation buttons grow again.

You are on a phone-sized screen (under 600px) You are on a tablet-sized screen (600px to 1023px) You are on a desktop-sized screen (1024px or wider)

Resize the window and this box changes. Only CSS is used here, no JavaScript.

/* Phone: the default */
main ul { grid-template-columns: 1fr; }

/* Tablet and up */
@media (min-width: 600px) {
    h1 { font-size: 1.8rem; }
    main ul { grid-template-columns: repeat(auto-fit, minmax(240px, 1fr)); }
}

/* Desktop and up */
@media (min-width: 1024px) {
    h1 { font-size: 2rem; }
}

6. Sticky header and fixed footer

The header uses position: sticky with top: 0, so it stays at the top of the screen while you scroll. The footer uses position: fixed with bottom: 0, so it is always visible. main has extra bottom padding so the footer never covers the last lines of a page.
